# Focus Room

A minimal, distraction-free focus timer designed to stay inside a single viewport.

## Features

- Focus, short break and long break modes
- One-task focus input
- Circular visual progress
- Day and night atmosphere
- Subtle rainy-window animation
- Fullscreen focus mode
- Custom timer durations
- Daily session count stored in LocalStorage
- Keyboard shortcuts
- Responsive single-screen layout with no page scrolling

## Keyboard shortcuts

- `Space` — start / pause
- `R` — reset
- `F` — fullscreen

## Built with

- HTML
- CSS
- JavaScript
- LocalStorage

No backend is required.
